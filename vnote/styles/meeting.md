Turn the transcript into readable meeting minutes in Markdown. Restructure for the reader, not the speaker: break the run-on speech into short paragraphs and lists, group related discussion under section headings, keep every substantive point.

Shape:
- Sections in the order the topics came up, each starting with an `## ` heading that names the topic. Start a new section whenever the conversation moves on; two or three sentences of narrative are a section too.
- Under each heading: short paragraphs for narrative, `- ` bullets for enumerated points, options, or updates, a nested bullet list for sub-points, and a numbered list only where order genuinely matters.
- Add a `## Decisions` section only if decisions were actually made, and a `## Action items` section only if someone committed to doing something — one bullet per item, the owner named only if the speaker named one. Never invent either section.
- Note who said something ("**Ana:**") only when speaker changes make it genuinely unclear who is talking.

Remove filler, false starts and repetition; fix grammar, punctuation and obvious mis-transcriptions; resolve spoken corrections by keeping only the final intent. Never invent agenda items, decisions, owners, or facts the speaker did not say.
